# Privacy

TFC opens files selected by the visitor and processes their pixels in browser
memory, one queued file at a time. Output files are created locally and saved
only when the visitor chooses to download them. Selected images and their names
are not sent to an application server.

The supplied application does not use cookies, local storage, a database,
analytics, advertising, user accounts or external conversion APIs. Closing or
reloading the page discards application state. Downloaded files remain in the
visitor's download folder until the visitor removes them.

When hosted, the web server still receives ordinary page requests and may record
IP addresses and access logs. A hosting provider, browser extension or modified
copy may add its own behavior. This document describes the unmodified source.


## Local tools

The built-in compressor presets, resize, crop, color picker, rotate, flip and enlargement tools process image data locally in browser memory. They do not upload selected files to a TFC application server. Browser memory limits still apply, and downloaded results remain on the visitor's device.

## External links

TFC may link to ClipSnap and ProPDF for optional tools. These websites are separate services and are not operated by Total Free Convert. If you follow an external link, their own privacy policy, terms and file-processing practices apply. TFC does not send your selected files to those services automatically.

## Local utility tools

Image-to-PDF, ZIP Creator, Unit Converter and Time Converter run locally in the browser/device. Selected files and entered values are not sent to a Total Free Convert server.
