# Contributing

Keep TFC usable as a static website on shared hosting. Do not introduce databases,
server-side conversion, mandatory accounts, remote uploads or external services.

Use English for visible text and documentation. Preserve keyboard access, mobile
layouts and clear error messages. Only advertise formats that are implemented;
document unsupported variants and browser limitations.

For a pull request, explain the user-visible change and how you checked it. For
format changes, use small generated or freely licensed fixtures and verify the
download with an independent viewer when possible. Do not commit personal files,
credentials, local machine paths or hosting configuration.
